数据清理回归测试
================

在项目目录执行：

    python -m unittest discover -s tests -v

仅使用标准库、TemporaryDirectory 和合成数据。隔离加载 storage.py，
不导入生产 config.py，不读取真实学生数据，也不依赖 API 或 Streamlit 安装。
设置页面测试通过 AST 隔离执行页面函数并使用 UI 替身验证确认门槛和会话清理；
未覆盖真实浏览器交互。

全量清理遍历 uploads 与 cache 的全部文件，包括没有导入记录的孤立文件、
隐藏文件和嵌套文件；保留目录、默认政策、环境配置和表单模板。
符号链接作为链接删除，不跟随删除外部目标；根目录为链接时拒绝清理。
文件删除或 JSON 重置失败时返回失败和错误详情，保留导入记录供排查/重试。
操作不是跨文件事务，失败时可能已有部分数据被删除。

管理页面要求勾选并准确输入“清空全部数据”，提交后清除当前会话的画像、
分析结果、上传控件和聊天内容，保留登录状态与联网偏好。
其他已打开会话的内存与用户已下载的副本不在服务器磁盘清理范围内。
当前 JSON 存储没有跨进程读写锁；部署清理时应暂停其他用户的导入和写入，
并关闭其他活动会话，避免并发写入重新产生数据。
